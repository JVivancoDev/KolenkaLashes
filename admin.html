Modo local (configura la URL del script)

Primeros pasos

  1. Despliega el código kolenka-apps-script.js en script.google.com
  2. Implementar → Nueva implementación → Aplicación web → Acceso: "Cualquier persona"
  3. Copia la URL generada y pégala abajo en "URL del Apps Script"
  4. Haz lo mismo en kolenka-lashes.html (variable APPS_SCRIPT_URL)
  5. Sube ambos archivos a tu repositorio de GitHub
